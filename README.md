🚗 Gesture_Drive

Control the road with your gestures!

Gesture_Drive is an interactive car game developed by Glitch Studio. The project combines gaming and programming to create an exciting driving experience.

🎮 About the Game

Gesture_Drive is designed to provide an engaging driving experience with interactive controls. Explore the game and discover its features!

✨ Features

- 🚘 Interactive car game
- 🎮 Engaging gameplay
- 🖥️ Web-based interface
- ⚡ JavaScript-powered game logic

🛠️ Technologies Used

- HTML — Webpage structure
- CSS — Styling and layout, if used in the project
- JavaScript — Game logic and interactions
- Python — Server-side functionality
- Batch (.bat) — Server startup script for Windows

📂 Project Files

File| Description
"index.html"| Main webpage
"game.js"| Game logic
"Server.py"| Python server
"Start-server.bat"| Windows server startup script

▶️ How to Run

1. Download or clone this repository.
2. Install Python if your server requires it.
3. Run "Start-server.bat" on Windows, if configured for your setup.
4. Open the local address displayed by the server in your browser.
